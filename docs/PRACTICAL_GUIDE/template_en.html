PlanX Urban Resilience — Practical Guide

Edition: {{EDITION}} | Companion: Academic Reference Manual | Author: Yusuf Eminoğlu

What this guide is: a practical companion to the academic reference manual. It documents all 45 PlanX Urban Resilience Processing tools - what each one computes, which inputs it needs, which parameters matter, and how to read the result - using real screenshots captured from actual QGIS runs on the plugin's own synthetic demo district. For the derivation of every formula, the modelling assumptions and the literature behind them, see the reference manual.
How the screenshots were made: a headless QGIS session runs each tool in turn, renders the input layers, the raw result, the styled result and the exact parameter values used, and writes them into this document. No figure is drawn by hand and no number is illustrative.
To create a PDF: in the browser press Ctrl+P (or Cmd+P) → Destination: Save as PDF → Paper: A4, margins: Default.
